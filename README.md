# OpenRouter Discord 봇

## 사용법
기본은 봇을 **@멘션**하면서 말을 거는 방식이에요.

예:
```
@봇이름 안녕! 오늘 날씨 어때?
```

**멘션 없이 대화하고 싶으면** 전용 채널을 하나 만들면 돼요:
1. 디스코드 서버에 채널 하나 새로 만들기 (예: `#ai-chat`)
2. 개발자 모드가 켜져 있는 상태에서 그 채널 우클릭 → **ID 복사(Copy Channel ID)**
3. `.env`(또는 Railway Variables)에 추가:
   ```
   AI_CHANNEL_ID=복사한_채널ID
   ```
4. 재배포 후, 그 채널에서는 멘션 없이 아무 말이나 치면 자동으로 답합니다. (다른 채널에서는 여전히 멘션 필요)

봇이 멘션을 감지하면 OpenRouter API로 질문을 보내고, 답변을 채널에 그대로 출력합니다.
같은 채널 안에서는 최근 대화(최대 10개)를 기억해서 이어지는 대화처럼 답할 수 있어요. (봇을 재시작하면 기억은 초기화됩니다)

## API 키 발급 & 요금 (소액 과금)

1. https://openrouter.ai 접속 → 이메일 또는 GitHub 계정으로 가입
2. 우측 상단 프로필 → **Keys** 메뉴 → **Create Key** 클릭 → 키 복사해서 보관
3. **크레딧 충전 필요**: 우측 상단 → Credits → 카드 등록 후 원하는 금액 충전 (예: $5~10). 이제부터는 무료 모델이 아니라서 충전이 있어야 작동함.

이 봇은 `anthropic/claude-haiku-4.5` 모델(Claude 계열 중 가장 저렴한 모델)을 사용하고, **실시간 웹 검색 기능**이 켜져 있어요.

- 채팅 자체: 입력 100만 토큰당 $1, 출력 100만 토큰당 $5 — 메시지 한 번에 보통 $0.001~0.003 수준
- 웹 검색: 검색 1회당 약 $0.005~0.015 (질문에 검색이 필요하다고 판단될 때만 자동으로 사용됨)
- $10 충전 기준으로 개인/친구용 봇이면 꽤 오래 씀. Railway처럼 OpenRouter도 콘솔에서 실시간 사용량 확인 가능.

특정 모델을 바꾸고 싶으면 `index.js`의 `MODEL` 값을 openrouter.ai/models 에서 원하는 모델 슬러그로 바꾸면 됩니다.

## 권한 관리 (관리자만 사용 허가 부여 가능)

기본적으로 아무도 사용 못 하고, **관리자(본인)** 와 관리자가 허락한 사람만 봇을 쓸 수 있어요.

**처음 설정:**
1. 디스코드 앱 → 설정 → 고급(Advanced) → **개발자 모드(Developer Mode)** 켜기
2. 본인 프로필 우클릭 → **ID 복사(Copy User ID)**
3. `.env` (또는 Railway Variables)에 추가:
   ```
   ADMIN_USER_ID=본인_유저ID
   ```
4. 봇을 재시작(또는 배포)하면 관리자 본인은 자동으로 사용 가능 상태가 됨.

**이후 권한 부여는 디스코드 안에서 명령어로:**
- `!허용 @사람` — 그 사람에게 사용 권한 부여
- `!허용해제 @사람` — 사용 권한 회수
- `!허용목록` — 지금 사용 가능한 사람 목록 확인

이 명령어들은 봇을 멘션할 필요 없이 채널에 그냥 입력하면 되고, 관리자 본인만 실행할 수 있어요 (다른 사람이 치면 거부됨). 부여/회수한 목록은 `allowed_users.json` 파일에 저장되어서 봇이 재시작해도 유지돼요 (단, Railway에서 리포지를 다시 배포하면 파일이 초기화되니 배포 자주 한다면 참고).

## 배틀그라운드 전적 조회

`!배그전적 스팀닉네임` 명령어로 이번 시즌 전적(판수, 승률, K/D, 평균 데미지)을 모드별로 보여줘요.

`!배그전적비교 닉네임1 닉네임2` — 두 사람이 같이 플레이한 모드 기준으로 K/D, 승률을 비교해서 누가 더 잘하는지 보여줘요. 각자의 전체 전적도 같이 나옵니다.

**API 키 발급 (무료):**
1. https://developer.pubg.com 접속 → 계정 생성 → API 키 발급
2. `.env`(또는 Railway Variables)에 추가:
   ```
   PUBG_API_KEY=발급받은_키
   ```

**참고:**
- 플랫폼은 스팀 기준으로 고정되어 있어요 (콘솔 계정은 지원 안 함)
- 분당 요청 10회 제한이 있어서, 너무 빠르게 여러 번 조회하면 잠깐 실패할 수 있어요
- 판수가 0인 모드는 결과에서 자동으로 빠져요

## 아이온2 캐릭터 검색

`!아이온2 서버명 닉네임` — 아이온2 캐릭터의 레벨, 아이템 레벨, 전투력, 길드, 보유 타이틀, 날개 정보를 보여줘요.

예: `!아이온2 이슈타르 기동이` (이슈타르 서버는 기본으로 등록되어 있어요)

**새 서버 등록 (관리자만):**
1. aion2tool.com에서 그 서버의 캐릭터를 한 번 검색
2. 주소창에 뜨는 `aion2tool.com/char/serverid=숫자/닉네임` 에서 그 숫자가 서버ID
3. 디스코드에서 `!서버추가 서버명 숫자ID` 입력 (예: `!서버추가 지켈 1020`)
4. 그다음부터는 `!아이온2 지켈 닉네임` 처럼 이름으로 바로 조회 가능

등록 안 된 서버는 숫자 ID를 직접 써도 됩니다: `!아이온2 1019 기동이`

**참고:** aion2tool.com은 공식 API가 아니라 그 사이트 자체 내부 API라서, 사이트 구조가 바뀌면 이 기능도 갑자기 안 될 수 있어요.

### 스펙업 분석

`!아이온2분석 서버명 닉네임` — 캐릭터의 장비/스탯/아르카나/데바니온 데이터를 AI에게 넘겨서, 현재 상태 요약과 다음에 투자하면 좋을 항목을 순서대로 조언받아요.

예: `!아이온2분석 이슈타르 기동이`

**주의:** 이건 aion2tool.com이 자체적으로 계산하는 정확한 "아툴 점수" 알고리즘을 그대로 재현한 게 아니라, AI가 데이터를 보고 일반적인 게임 지식으로 조언하는 방식이에요. 그래서 사이트의 "스펙업 순서" 탭만큼 정밀하진 않고, 참고용으로만 봐주세요. 이 명령어는 일반 대화와 같은 AI 모델을 쓰기 때문에 별도의 소액 비용(토큰)이 듭니다.

### 유저 간 비교

- `!아이온2비교 서버명 닉네임1 닉네임2` — 아이템 레벨/전투력 숫자만 빠르게 비교 (AI 안 씀, 비용 없음)
- `!아이온2분석비교 서버명 닉네임1 닉네임2` — 장비/스탯까지 AI가 종합 비교해서, 누가 우위인지와 뒤처지는 쪽이 뭘 올려야 할지 조언 (소액 토큰 비용)

둘 다 같은 서버 소속 캐릭터끼리 비교하는 걸 가정해요. 다른 서버 캐릭터를 비교하고 싶으면 알려주시면 기능 추가해드릴게요.

예: `!아이온2분석비교 이슈타르 기동이 친구닉네임`

## 서버 관리 (특정 유저 잠깐 침묵시키기)

봇에게 서버에서 **"멤버 타임아웃(Timeout Members)"** 권한을 주면, 관리자(ADMIN_USER_ID)가 아래처럼 쓸 수 있어요.

- `!타임아웃 @유저` — 1분간 채팅 금지 (기본값)
- `!타임아웃 @유저 5` — 5분간 채팅 금지
- `@유저 죽여` 또는 `@유저 침묵시켜` — 재미용 트리거, 1분간 채팅 금지

관리자 본인만 사용 가능하고, 다른 사람이 시도하면 거부돼요. 봇의 서버 내 역할이 대상 유저보다 높아야 작동합니다 (디스코드 서버 설정 → 역할에서 봇 역할을 위로 올려주세요).

## 실행 방법

1. 이 폴더에서 의존성 설치
   ```
   npm install
   ```

2. `.env.example`을 `.env`로 이름 변경하고 값 채우기
   ```
   DISCORD_TOKEN=디스코드_봇_토큰
   OPENROUTER_API_KEY=OpenRouter_API_키
   ADMIN_USER_ID=본인_디스코드_유저ID
   ```

3. 봇 실행
   ```
   npm start
   ```

4. 터미널에 `로그인 완료: 봇이름#0000` 이 뜨면 성공. 이제 디스코드 채널에서 봇을 멘션해보세요.

## 체크할 것 (막힐 때)
- Discord Developer Portal → Bot 탭 → **Privileged Gateway Intents**에서 **Message Content Intent**가 켜져 있어야 메시지 내용을 읽을 수 있습니다.
- 봇을 서버에 초대할 때 권한에 "메시지 보내기(Send Messages)"가 포함되어 있어야 합니다.
- 크레딧이 바닥나면 API 요청이 실패해요. OpenRouter Credits 페이지에서 잔액을 가끔 확인하고, 필요하면 Auto Recharge(자동 충전)를 설정해두면 편해요.

## 배포 (Railway 기준)
1. 이 폴더의 파일들을 GitHub 리포지에 올림 (.env는 올리지 않기)
2. Railway → New Project → Deploy from GitHub repo → 해당 리포지 선택
3. Variables 탭에서 DISCORD_TOKEN, OPENROUTER_API_KEY, ADMIN_USER_ID 등록
4. Deploy Logs에서 "로그인 완료"가 뜨면 정상 작동
